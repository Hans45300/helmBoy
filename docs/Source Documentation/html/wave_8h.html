Detailed Description

Génération de formes d'onde et tables de lookup band-limited pour mopo.

Contient la classe WaveLookup qui construit des tables de recherche pour plusieurs formes d'onde (sinus, carré, dent de scie, triangle) et la classe Wave fournissant des utilitaires pour générer des formes d'onde mathématiques et band-limited (BL) selon un type.
