Detailed Description

Gestion des voix polyphoniques et d'une voix individuelle dans mopo.

Définit la structure VoiceState, la classe Voice pour l'état d'une voix individuelle et VoiceHandler qui gère l'allocation, l'activation et le routage des voix pour la synthèse polyphonique.
