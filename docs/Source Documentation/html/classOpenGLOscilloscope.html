Detailed Description

Oscilloscope component rendered with OpenGL.

Uses an externally provided memory buffer of floats to draw waveform traces. Designed to be lightweight and updated from the audio thread via lock-free buffers (the pointer provided to setOutputMemory must remain valid while in use).
