Detailed Description

template<std::copyable T>
class mopo::CircularQueue< T >::iterator

Forward iterator over the occupied elements of the queue.

The iterator stores pointers into the internal buffer and wraps from the end of the allocated storage back to the front. It is intentionally lightweight (no reference to the parent queue) and meant for single- threaded iteration by the consumer.
