34 // A delay/attack/hold/decay/sustain/release envelope.
35 // The attack is a linear scale and completes in the exact amount of time.
36 // The decay and release are exponential and get down to the _CLOSE_ENOUGH_
37 // level in the specified amount of time.
38 //
39 // The reason for this is that technically the decay and release
40 // take an extremely long time to finish because they are exponential. But
41 // users are used to specifying the amount of time the decay or release take
42 // so we make this compromise of _CLOSE_ENOUGH_.
