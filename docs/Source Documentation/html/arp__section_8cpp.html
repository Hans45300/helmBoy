Detailed Description

Implementation of the ArpSection UI for the arpeggiator.

Provides painting and layout logic used by the arpeggiator controls displayed in the synth's editor. Controls include frequency/tempo knobs, sync selector, gate, octave count, pattern selector and the enable button.
