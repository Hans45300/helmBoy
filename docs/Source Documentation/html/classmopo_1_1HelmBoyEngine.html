Detailed Description

The main synthesis engine for HelmBoy synthesizer.

HelmBoyEngine is the central audio processing unit that orchestrates all synthesis components including oscillators, filters, effects, and modulation sources. It inherits from both HelmBoyModule (for modular architecture) and NoteHandler (for MIDI note processing).

The engine manages:

  • Polyphonic voice allocation through HelmBoyVoiceHandler
  • Real-time audio processing pipeline
  • Modulation routing and connections
  • Parameter automation and control
  • MIDI note on/off events
