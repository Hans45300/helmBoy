HelmBoy Documentation

Introduction

HelmBoy is a polyphonic software synthesizer built around the mopo processor graph and JUCE application/plugin APIs. This reference combines the API extracted from the source with the developer guides below.

Developer guides

  • Architecture du logiciel describes the repository layers, host lifecycles and global audio signal path.
  • Paramètres et état documents controls, host automation and patch persistence.
  • MIDI 1.0 et décodeur UMP documents the active MIDI 1.0 path and the explicit, limited UMP decoder.
  • Interface, visualisations et threads describes GUI updates, visual snapshots and CPU-rendered components.
  • Développement et tests ciblés lists build targets and focused test options.

Source layout

  • src/common: shared synth façade, controls, persistence and MIDI.
  • src/synthesis: HelmBoy engine, voice graph and synthesis modules.
  • src/editor_sections and src/editor_components: JUCE interface.
  • mopo/src: processor graph, parameters and DSP building blocks.
  • src/plugin and src/standalone: host-specific lifecycle adapters.

The guides describe current source behavior; generated API pages provide declarations and symbol-level details. Neither is a claim of runtime or host certification.
