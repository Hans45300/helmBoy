27/*
28 * Système de couleurs rationalisé HelmBoy
29 * =======================================
30 *
31 * Philosophie :
32 * - Palette FROIDE : Bleu de référence #03a9f4 et ses variations (audio, sélections)
33 * - Palette CHAUDE : Orange de référence #ff7043 et ses variations (logos, états actifs)
34 * - Gris NEUTRES : Conservés pour fonds, textes et interfaces (stabilité visuelle)
35 *
36 * Cette approche garantit :
37 * - Cohérence visuelle par familles de couleurs
38 * - Lisibilité préservée avec les gris neutres
39 * - Hiérarchie claire : froid=fonctionnel, chaud=actif/important
40 */
