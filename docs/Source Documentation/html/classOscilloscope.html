Detailed Description

Real-time audio waveform visualization component.

Oscilloscope provides real-time visualization of audio signals, displaying waveforms as they are generated by the synthesizer. This component offers valuable visual feedback for sound design, allowing users to see the immediate effects of parameter changes on the generated audio signal.

Key Features

  • Real-time Display: Live audio waveform visualization
  • Memory Integration: Direct connection to synthesis engine output
  • Smooth Rendering: Anti-aliased waveform drawing
  • Background Caching: Optimized rendering performance
  • Configurable Updates: Adjustable refresh rate and feedback settings
  • Path Generation: Efficient waveform path construction

Display Characteristics

The oscilloscope provides:

  • Time Domain View: Traditional oscilloscope-style waveform display
  • Amplitude Scaling: Automatic or manual amplitude scaling
  • Trigger Options: Various triggering modes for stable display
  • Grid Overlay: Optional reference grid for measurement
  • Color Coding: Customizable waveform colors and styling

Performance Optimization

The oscilloscope is optimized for real-time use:

  • Efficient Path Updates: Only redraws when necessary
  • Background Caching: Reduces redraw overhead
  • Timer-based Updates: Controlled refresh rate
  • Memory Ownership: Caller-owned waveform snapshot (legacy API)
  • SIMD-friendly Operations: Vectorized path generation

Visual Customization

Supports customization of:

  • Waveform color and thickness
  • Background styling and grid patterns
  • Update rate and smoothing
  • Amplitude scaling and offset
  • Trigger sensitivity and mode
