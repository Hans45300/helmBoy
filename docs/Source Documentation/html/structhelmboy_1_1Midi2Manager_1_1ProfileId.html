Detailed Description

MIDI 2.0 Profile identifiers (5-byte specification).

Profiles define standard configurations for different instrument types or control modes. They enable automatic capability negotiation between the plugin and MIDI 2.0 controllers.

Standard Profiles (byte_1 = 0x00):
  • 0x01: General MIDI 2 (GM2)
  • 0x02: Polyphonic Expression (MPE)
  • 0x10: Drawbar Organ
  • 0x20: Piano
  • 0x21: Electric Piano
Example Usage:
// Enable MPE profile on all channels
Midi2Manager::ProfileId mpe = {0x00, 0x02, 0x01, 0x00, 0x00};
midi2->enableProfile(mpe, -1);
// Enable GM2 profile on channel 0
Midi2Manager::ProfileId gm2 = {0x00, 0x01, 0x01, 0x00, 0x00};
midi2->enableProfile(gm2, 0);
