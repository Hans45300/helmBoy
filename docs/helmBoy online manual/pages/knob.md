# Knob Controls

## Overview

![knob example](../pictures/Knob.png)

Knobs are the primary interface elements in helmBoy for adjusting continuous parameters.

## Interaction

- **Click and drag**: Vertically to adjust value
- **Shift + drag**: Fine adjustment mode
- **Double-click**: Reset to default value
- **Mouse wheel**: Scroll to adjust (when hovering)

## Visual Feedback

- Current value is displayed when hovering
- Knob rotation indicates parameter value
- Color indicates parameter type and modulation state
