# Modulation Matrix

## Overview

The modulation matrix allows routing modulation sources to any parameter destination, creating dynamic and evolving sounds.

## Modulation Sources

### Envelopes

- Amplitude Envelope
- Filter Envelope
- Modulation Envelope

### LFOs

- Mono LFO 1-4
- Poly LFO 1-2

### Performance

- Mod Wheel
- Pitch Bend
- Aftertouch
- Velocity

### Other

- Step Sequencer
- Random
- Note Number (keyboard tracking)

## Modulation Destinations

Nearly any parameter can be modulated:

- Oscillator parameters (pitch, volume, waveform)
- Filter parameters (cutoff, resonance, drive)
- Effect parameters (delay time, reverb mix)
- LFO parameters (rate, amplitude)
- Envelope parameters

## Creating Modulations

1. **Select Source**: Choose a modulation source
2. **Select Destination**: Choose the parameter to modulate
3. **Set Amount**: Adjust modulation depth (positive or negative)
4. **Bipolar vs Unipolar**: Choose modulation polarity

## Modulation Amount

- **Positive values**: Modulation increases parameter value
- **Negative values**: Modulation decreases parameter value
- **Zero**: No modulation
