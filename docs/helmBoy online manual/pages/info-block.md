# Info Block

## Overview

![Info Block example](../pictures/Info%20Block.png)

The info block displays real-time information about the current state of helmBoy.

## Displayed Information

### Preset Name

Current loaded preset or "Init" if initialized.

### Voice Count

Number of currently active voices.

- Useful for monitoring polyphony usage
- Shows voice stealing behavior

### CPU Usage

Current CPU load percentage.

- Helps optimize performance
- Indicates if settings need adjustment

### MIDI Activity

Visual indicator for incoming MIDI messages.

### Parameter Value

When hovering over a control:

- Shows parameter name
- Displays current value
- Shows units (Hz, dB, %, etc.)

## Modulation Display

When a parameter is modulated:

- Shows modulation sources
- Displays modulation depth
- Color-coded by source type
