# Main Logo

## Overview

![Main logo section example](../pictures/Main%20logo.png)

The helmBoy logo in the interface provides access to utility functions and information.

## Functions

### Click Actions

#### Single Click

Opens the main menu with options:

- Save Preset
- Load Preset
- Initialize Patch
- Settings
- About

#### Right Click

Quick access menu (if available):

- Recent presets
- Favorites
- User folders

## Menu Options

### Save Preset

Save current sound as a new preset.

- Enter preset name
- Choose folder/category
- Add author and description

### Load Preset

Browse and load saved presets.

- Factory presets
- User presets
- Imported presets

### Initialize Patch

Reset all parameters to default "init" sound.

### Settings

Access global settings:

- Audio device configuration
- MIDI device selection
- UI preferences
- Performance options

### About

Display version and licensing information.
